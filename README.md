# Clonify Studio · beta

Tu estudio de contenido con IA. Pones en una pizarra lo que tienes (vídeos, notas de voz, fotos, enlaces) y tu IA lo convierte en reels, vídeos editados, presentaciones o clases. Trabaja en tu ordenador, con tu cuenta de Claude.

## Descargar

- **[⬇ Descargar para Windows](https://github.com/Eugeoller/clonify-studio-descargas/releases/latest/download/Instalar-Clonify-Studio.exe)** (unos 100 MB)
- **[⬇ Descargar para Mac con chip Apple](https://github.com/Eugeoller/clonify-studio-descargas/releases/latest/download/Instalar-Clonify-Studio-mac-arm64.dmg)** (M1, M2, M3, M4…; unos 115 MB)
- **[⬇ Descargar para Mac con Intel](https://github.com/Eugeoller/clonify-studio-descargas/releases/latest/download/Instalar-Clonify-Studio-mac-x64.dmg)** (unos 120 MB)

¿Qué Mac tienes? Menú de la manzana  → **Acerca de este Mac**: pone «Chip Apple» o «Procesador Intel».

## Instalarlo en Windows

1. Abre el archivo que has descargado.
2. Puede que Windows diga **«Windows protegió su PC»**. Sale porque es una versión de prueba aún sin firmar. Pulsa **Más información** y luego **Ejecutar de todas formas**.
3. Se instala solo en un minuto, sin pedir permisos de administrador, y se abre.
4. La primera vez pulsa **Instalar Claude Code**. Tarda uno o dos minutos.
5. Después pulsa **Conectar** y entra con tu cuenta de Claude.

## Instalarlo en Mac

1. Abre el archivo `.dmg` que has descargado.
2. Arrastra **Clonify Studio** a la carpeta **Aplicaciones**.
3. Ábrelo desde Aplicaciones. La primera vez, el Mac pregunta si quieres abrir una app descargada de internet: pulsa **Abrir**. Está firmada y revisada por Apple.
4. La primera vez pulsa **Instalar Claude Code**. Tarda uno o dos minutos.
5. Después pulsa **Conectar**: se abre la Terminal para que entres con tu cuenta de Claude.

## Qué necesitas

- Windows 10 u 11, o un Mac con macOS 12 (Monterey) o posterior.
- Una cuenta de Claude con plan **Pro o Max**.

## Actualizaciones

El Studio se actualiza solo. Cuando haya una versión nueva, verás **Actualizar** arriba a la derecha.

Tus creaciones se guardan en la carpeta **Documentos › Clonify Studio**. Si desinstalas el Studio, siguen ahí.
