## Instalarlo en Windows

1. Abre el archivo que has descargado. Baja la última versión del Studio, comprueba que es la original (firmada por **Marea Kiss LLC**) y la instala sola, en un minuto, sin pedir permisos de administrador. Luego se abre.
2. Puede que antes Windows diga **«Windows protegió su PC»**: el Studio es nuevo y Windows aún no lo conoce. Comprueba que pone **Editor: Marea Kiss LLC**, pulsa **Más información** y luego **Ejecutar de todas formas**.
3. Entra con tu cuenta.
4. La primera vez pulsa **Instalar Claude Code**. Tarda uno o dos minutos.
5. Después pulsa **Conectar** y entra con tu cuenta de Claude.

¿No te funciona el instalador? Descarga el [instalador completo para Windows](https://github.com/Eugeoller/clonify-studio-descargas/releases/latest/download/Clonify-Studio-completo.exe) (unos 100 MB).

## Instalarlo en Mac

1. Abre el archivo `.dmg` que has descargado.
2. Arrastra **Clonify Studio** a la carpeta **Aplicaciones**.
3. Ábrelo desde Aplicaciones. La primera vez, el Mac pregunta si quieres abrir una app descargada de internet: pulsa **Abrir**. Está firmada y revisada por Apple.
4. La primera vez pulsa **Instalar Claude Code**. Tarda uno o dos minutos.
5. Después pulsa **Conectar**: se abre la Terminal para que entres con tu cuenta de Claude.

## Instalarlo en Linux

Hay dos formas. Si no sabes cuál, usa la **AppImage**.

- **AppImage** (no se instala: se abre tal cual). Haz clic derecho en el archivo → **Propiedades** → marca **Permitir ejecutar como programa** y ábrelo con doble clic. Desde la terminal: `chmod +x Clonify-Studio-linux-x86_64.AppImage` y `./Clonify-Studio-linux-x86_64.AppImage`.
- **.deb** (Ubuntu y Debian). Ábrelo con doble clic y pulsa **Instalar**, o desde la terminal: `sudo apt install ./Clonify-Studio-linux-amd64.deb`. Sale en tus aplicaciones como **Clonify Studio**.

Después, como en los demás:

1. Entra con tu cuenta.
2. La primera vez pulsa **Instalar Claude Code**. Tarda uno o dos minutos.
3. Después pulsa **Conectar**: se abre una terminal para que entres con tu cuenta de Claude.

Linux es lo más nuevo del Studio: si algo no va, cuéntaselo a Euge.

## Qué necesitas

- Windows 10 u 11; un Mac con macOS 12 (Monterey) o posterior; o un Linux de 64 bits (Ubuntu 22.04 o posterior, Debian 12 o posterior).
- Una cuenta de Claude con plan **Pro o Max**.

## Actualizaciones

El Studio se actualiza solo. Cuando haya una versión nueva, verás **Actualizar** arriba a la derecha. (En Linux, con el `.deb`, te pide la contraseña del ordenador para actualizar.)

Tus creaciones se guardan en la carpeta **Documentos › Clonify Studio**. Si desinstalas el Studio, siguen ahí.
